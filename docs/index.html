常见工具配置模板

按不同客户端对 `/v1` 路径的拼接习惯区分，避免 404 路径重复错误。

提示：Claude Code 会自动在 ANTHROPIC_BASE_URL 后拼接 /v1/messages，请填写根域名 https://apikey.fan（不要多加 /v1）。 
export ANTHROPIC_BASE_URL="https://apikey.fan"
export ANTHROPIC_AUTH_TOKEN="your_apikey_fan_key"

# 或者写入 ~/.claude/settings.json

# }

标准 OpenAI SDK 需在 base_url 中包含 /v1，密钥建议始终从环境变量读取。

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://apikey.fan/v1",
    api_key=os.environ["API_KEY"],
)

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)

仓库内置 scripts/check_api.py（仅用 Python 标准库），可在本地测量模型列表与对话延迟。

git clone https://github.com/HJP-520/apikey-fan-quickstart.git
cd apikey-fan-quickstart
cp .env.example .env
# 在 .env 中填入你的 API_KEY 后运行：
python scripts/check_api.py --mode all
